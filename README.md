# Auralis Med Tech & SAFE VAC – Official Website

A modern, responsive, and interactive website designed for **Auralis Med Tech** and its flagship Negative Pressure Wound Therapy (NPWT) device, **SAFE VAC**.

## 📁 File Structure
- `index.html` — Main website layout featuring the Hero section, Clinical Indications, Interactive NPWT Simulator, Comparison Table, and Partnership Form.
- `styles.css` — Modern design system with responsive layouts, medical color accents, and clean UI components.
- `script.js` — Interactive simulator logic, timer state, and contact form handling.
